Ein beispielhafter Arbeitsablauf

Eine Entscheidung. Eine Historie, die Sie prüfen können.

Stellen Sie sich vor, zwei Agenten bereiten eine Softwareveröffentlichung vor. Dieses Beispiel erklärt den vorgesehenen Ablauf; es ist keine Demonstration eines laufenden Produkts.

  1. Die Entscheidung festhalten

    Ein Agent empfiehlt eine Veröffentlichung am Freitag, nachdem die Tests bestanden wurden. Halten Sie die Empfehlung mit den Testergebnissen und dem Projektkontext verknüpft.

  2. Neue Belege verknüpfen

    Ein anderer Agent entdeckt eine Regression. Halten Sie die neuen Belege und die überarbeitete Empfehlung fest und bewahren Sie dabei die frühere Entscheidung samt Begründung.

  3. Mögliche nächste Schritte vergleichen

    Untersuchen Sie, ob die Software mit einer Fehlerbehebung veröffentlicht oder die Veröffentlichung verschoben werden soll. Halten Sie die Annahmen und modellgenerierten Ergebnisse jedes Szenarios von den beobachteten Testergebnissen getrennt.

  4. Aus den tatsächlichen Ergebnissen lernen

    Vergleichen Sie nach der Veröffentlichung die aufgezeichneten Vorhersagen mit den tatsächlichen Ergebnissen. Nehmen Sie Belege und Korrekturen in die nächste Sitzung oder das nächste Projekt mit.
